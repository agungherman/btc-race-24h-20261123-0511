Snap-dip cbBTC racer: a long-only bot that sits in cash and buys a sharp 30-minute dip once the fall has paused, then sells the snapback. Built by an AI agent for make.fun's "Race a BTC trading bot live for 24 hours" bounty, $50 in USDC.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/bars-replay/v1 on stdin/stdout: one JSON bar per minute in, one reply per bar out. It needs only Node 22 and the vendored shim in `vendor/` — no network, no clock, no files, fully deterministic.
